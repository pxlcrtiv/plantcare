## 3. CapCut free + Buffer free setup guide (concise)

**CapCut free (video, ~20 min/video once templated):**
1. CapCut desktop/mobile free → New project 9:16 → import 2–3 stock plant clips (Pexels/Pixabay) or your own phone footage.
2. Audio → Text-to-speech (free AI voiceover) → paste §1 script → pick friendly voice, 1.0–1.1x.
3. Captions → Auto-captions → style: bold white + dark stroke, top-third placement (Seed-of-Life green accent keyword).
4. Overlay: screen-record the PlantCare ID/diagnosis flow (3–5s) → picture-in-picture at Solution beat.
5. End card 2s: Seed of Life logo + "PlantCare — Never kill another plant · 3 months Premium free".
6. Export 1080×1920 → save as template (duplicate per post, swap plant + hook).

**Buffer free (scheduling, 3 channels):**
1. buffer.com free → connect TikTok + Instagram + YouTube (3-channel limit; X/Reddit = manual/post-native).
2. Settings → time slots per channel: 12:00pm, 7:00pm, 8:30pm local (add 10am/12pm Sat–Sun).
3. Upload week's batch (7–14 videos) → paste caption + hashtags from §2 → first comment = CTA link (Play listing).
4. Later alternative: later.com free (30 posts/mo) if Buffer limits hit — same slots.
5. Daily 15 min: reply to comments, pin CTA question, duet/stitch one plant-rescue video.

HITL boundary: human owns all account credentials + actual posting; agent prepares scripts/captions only.
