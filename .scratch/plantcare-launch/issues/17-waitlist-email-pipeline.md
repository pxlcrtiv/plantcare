# 17 — Waitlist → launch email pipeline

Type: task
Status: open
Blocked by: —

## Question

The waitlist captured signups via Formsubmit.co → GitHub noreply email. But there's no mailing list, no nurture sequence, and no launch announcement plan. The research mentions ConvertKit (free tier: 10,000 subscribers) but never made a ticket. The waitlist is Phase 1's only asset — it currently dead-ends. Without a launch email, those signups go cold.

Path:

1. **Migrate to ConvertKit** (or Buttondown/Mailchimp free tier): export waitlist emails from GitHub notifications → import into mailing list. Set up a simple welcome automation ("Thanks for signing up — launch coming soon").
2. **Launch announcement email**: draft the email (excitement + early-access link + "reply with feedback" CTA). Schedule for launch day.
3. **Ongoing nurture**: decide cadence (bi-weekly? monthly?) and content (plant care tips, app updates, behind-the-scenes). Keep it light — the research warns against over-emailing.
4. **Waitlist page update**: the current Formsubmit form could also feed directly into the mailing list (ConvertKit has an embeddable form). Replace Formsubmit with the mailing list provider's form.

## Checklist

- [ ] Mailing list provider selected (ConvertKit free tier recommended)
- [ ] Waitlist emails exported + imported
- [ ] Welcome automation set up
- [ ] Launch announcement email drafted + scheduled
- [ ] Waitlist page updated to feed directly into mailing list
